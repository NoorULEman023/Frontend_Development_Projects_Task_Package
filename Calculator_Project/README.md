#  Calculator Project

##  Project Overview

The **Calculator Project** is a responsive web application developed using **HTML5**, **CSS3**, and **Vanilla JavaScript**. It performs basic arithmetic operations with a clean, modern user interface. The project is designed to help beginners understand DOM manipulation, event handling, JavaScript logic, and responsive web design.

This calculator works directly in the browser without requiring any external libraries or frameworks.

#  JavaScript Logic Explanation

The calculator follows these steps:

1. Detect which button the user clicks.
2. Store the entered values as a mathematical expression.
3. Update the display instantly.
4. Evaluate the expression when the "=" button is pressed.
5. Display the calculated result.
6. Handle invalid expressions by showing an error message.
7. Allow keyboard input for easier usage.

The project uses JavaScript event listeners to detect both mouse clicks and keyboard input.

#  How Calculations Work

The calculator stores the entered expression as text.

Example:

```
15+20/5
```

When the equals (`=`) button is clicked:

* The expression is evaluated.
* The result is displayed.
* The previous calculation is shown in the history section.
* If the expression is invalid, an error message is displayed.
